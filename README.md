# Employment Analytics Dashboard (Team B14)

Interactive Python web app for employment analytics, aligned with SDG 8.

## Setup
1. `python -m venv venv` then activate it
2. `pip install -r requirements.txt`
3. `streamlit run app.py`

## Who owns what
| Student | Page | CSV |
|---|---|---|
| Member 1 | pages/1_Unemployment.py | data/unemployment.csv |
| Member 2 | pages/2_Job_Market.py | data/jobs.csv |
| Member 3 | pages/3_Wages.py | data/salaries.csv |
| Member 4 | pages/4_Workforce_Inclusion.py | data/labour_participation.csv |

## Data
The CSVs in `data/` were cleaned from public datasets (Kaggle, World Bank) by `scripts/prepare_data.py`.
